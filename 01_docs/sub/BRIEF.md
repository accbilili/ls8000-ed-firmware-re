import sys

pc = 0x27DC4 - BASE
for _ in range(200):
    sz, nm, a1, a2, nxt = h.decode(pc)
    if nm is None:
        print(f'0x{pc+BASE:06X}  .byte 0x{d[pc]:02X}')
        pc += 2
        continue
    print(f'0x{pc+BASE:06X}  {nm:<9} ' + ', '.join(x for x in (a1, a2) if x))

## 3. 已确认的固件事实（本轮可直接引用，不必重新证明）

- H8/300H，大端，16 位定长指令基。`jsr @aa:24`=0x5E、`jmp @aa:24`=0x5A 各带 3 字节绝对地址；`bsr d:16`=0x5C 带 2 字节**相对**偏移。
- **`bsr` 不编码绝对地址**，所以"某函数 0 引用"必须再查 `bsr` 可达区，否则结论无效。
- **禁止用字节模式搜索找代码语义**：H8 指令密度极高，`0xFF` 都能解码成合法指令，字节搜索在代码区必然大量假阳性。可靠锚点只有静态数据表与直接跳转目标。
- 段1 入口 `0x10600`，段2 入口 `0x20600`，主循环 `0x020B84`，命令分派器 `0x020E86`。
- SCSI 分派表 `0x03E2E8`（20 条），内部命令表 `0x03EBC0`（26 条 × 16 B），主机码映射表 `0x03E390`（48 条 × 4 B），地址白名单 `0x03ED60`。
- CDB 缓冲 `0x40043C`（CDB[0]）、`0x40043D`（CDB[1]）、`0x40043E`（CDB[2]）。
- E0 子功能码落 `0x400C55`；片夹类型码落 `0x400D79`（两者无数据流，别混）。
- 同步原语 `0x010B56`（设备就绪等待，206 次引用）。
- 数学：32 位乘 `0x018E1E`、除 `0x01872E`、软件双精度 `0x018AA0`、双精度转整 `0x01876A`。
- **（2026-10-24 第三～五轮更正）引导块镜像本地就有**：`D://DS//TEST//LS8000//LS8000_bootblock.bin`（64 KB，地址=文件偏移）与 `LS8000_full_512K.bin`（512 KB）——引导块侧分析已全部完成（表 `0x0000` 92 项、复位 `0x180`+`0x4001` 选段、缝隙 `0x192`、设置记录 33 B、flash 同址写）。`0x400408` 也**不是**"只写不读"：它是应用自己的 E0/C1 参数暂存区（4 写 + 5 处地址装入 + ≥1 处真读）。**不要在这上面浪费轮次，也不要按旧说法放弃。**
