## 0. 一句话结论

**图像路径的骨架已解通：采集参数（ASIC `0x2001xx`）→ 逐行描述符（`0x200142`，12 字节，由按行参数表 `0x3F104/0x3F108` 合成）→ 曝光启动（`0x200001 |= 0xC0`）→ 采集完成（`0x200001` bit6）→ 走片同步（`0x4202A4`==7）→ 行缓冲指针回填（`0x448FEE`→`0x400416`）。**
「曝光/gamma/位深」的**寄存器位域**与「像素从 ASIC 缓冲到 RAM 的搬运路径」仍未逐位落定——这是剩下的最后一段。

## 1. 采集配置层：ASIC 寄存器组 `[实证]`

| 寄存器 | 宽度 | 来源 / 作用 | 写入点 |
|---|---|---|---|
| `0x200102` | byte | **采集模式字节**：`0xE2` / `0x62` / `0x22|位域` | `0x02D028`、`0x02D06E`、`0x02D09A`、`0x02D140`、`0x02D1B4` |
| `0x200181` | byte | 采集控制字节 = `0x0D` | `0x02D202`、`0x02D2B0` |
| `0x200182/184/186/188` | 4×u16 | **参数组 1**（清零或按 `0x4206EC` 条件清） | `0x02D030`–`0x02D044` 等 |
| `0x200194/196/198/19A` | 4×u16 | **参数组 2** | 同上 |
| `0x2001A4/A5/A6` | byte×3 | 采集辅助参数 | `0x02D226`、`0x02D312`、`0x02D31E` |
| `0x2001C0` | byte | 模式位 `0x20`，**由 `0x4007C9` 决定** | `0x02D29A` |
| `0x2001C2` | u16 | ← `0x400D5E` | `0x02D1E4` |
| `0x2001C4` | u16 | ← `0x400D62` | `0x02D1F0` |
| `0x2001C6` | u16 | ← `0x400D60` − 1 | `0x02D210` |
| `0x2001C8` | u16 | ← `0x400D62` + `0x400DF8` − 1 | `0x02D21E` |
| `0x200142`–`0x200153` | 12–16 B | **行采集描述符**（见 §3） | `0x02D4CC`→`0x033810` |
| `0x200001` | byte | **曝光/采集启动**（`|=0xC0`）；**bit6 = 采集完成** | `0x01358C`、`0x0135A8`、`0x013776`、`0x0214B2`、`0x028540`、`0x035EF0` |
| `0x200002` | byte | **状态**：bit5 = 缓冲/DMA 就绪、bit3 = 忙 | `0x0214BA`、`0x028546`、`0x035FFA`、`0x035ECA` |

**`0x02D200`（公共前置，所有采集配置都先过它）**：
```
@0x200181 = 0x0D
@0x2001C6 = @0x400D60 − 1        ; 行宽/行数类
@0x2001C8 = @0x400D62 − 1
@0x2001A4 = 0 ; @0x2001A5 = 0
@0x200142 = 0x83 ; @0x200143 = 1 ; @0x200144 = 1
@0x200147 = 0 ; @0x200148 = 0 ; @0x200149 = 0
@0x20014B = 2 ; @0x20014C = 0 ; @0x20014D = 0 ; @0x20014E = 0
@0x200152 = 0 ; @0x200153 = 0
@0x2001C0 = (@0x4007C9 ? 0x20 : 0)      ; 模式位随「精细/快速」标志
@0x2001A6 = 0
```

**`0x02D0DE`/`0x02D148`（模式字节合成）**：`r1 = 0x02 | 0x20`；若 `@0x4206EC == 3` 再 `bset #7` 并清组 1（`0x200182-188`）；若 `@0x41FFA4 == 1` 且 `@0x4206EC != 0` 再 `bset #6`；最后 `0x200102 = r1`。
⇒ **`0x200102` 的 bit7/bit6/bit5 是三个独立模式开关**（扫描分辨率档 `0x4206EC`、标志 `0x41FFA4`、恒置 bit5）。

**`0x02D000`（曝光就绪等待）**：轮询 `@0xFFFF54` 的 bit2，最多 **20 次**（`cmp.w #0x0014, e0`），返回 0/1。
⇒ **`0xFFFF54` bit2 = 曝光/行就绪位**。

## 2. 逐行时序（主扫描循环 `0x035E20`–`0x036260`）`[实证]`

**分段结构**：
```
段号  r2l
每段行数  @0x4202DD
段内行号  r2l / @0x4202DD      (0x035EC6 divxu.b)
```

**每行**（`0x035EE8` 起）：
```
① jsr 0x02D4CC            打包 12 B 行采集描述符 → 0x200142
② r0l = @er3 ; r0l |= 0xC0 ; @er3 = r0l    ★ 启动曝光（0x200001）
③ btst #6, @er3 ; bne 自旋                   ★ 等采集完成
④ r0l = @0x4202A4 ; cmp #0x07 ; beq 继续    ★ 等走片轴就绪
   否则 jsr 0x010B56（设备就绪等待）后重试
⑤ e5 += r5 ; 与 e2（总行数）比较
```
**另一变体**（`0x035FF6`）：先 `btst #5, @0x200002`（等缓冲就绪）→ 再启动曝光 → 等 bit6 → 等 `0x4202A4`==7 → `jmp 0x035F5E`。

**行末**（`0x036218`）：
```
@0x449020 ++                       行号
与 @0x449021 比较（总行数？）
相等时：@0x400416 = @0x448FEE        ★ 行缓冲指针回填
bclr #4, @0xFFFF2E                 清某个就绪位
```
**段末**（`0x035E64` / `0x035EB0`）：`jsr 0x02A2F6`（参数 `r1 = 0x09C4 = 2500`、`e0 = r5`）或 `jsr 0x02AD0A`（2 个栈参数）——**走片步进**。

## 3. 行采集描述符与按行参数表 `[实证]`

**`0x02D4CC`（打包器，30 条）**：在 `0x440FE0` 组 12 字节，然后 `jsr 0x033810(er0=0x440FE0, er1=0x200142, r0=0x0C)` 写入 ASIC。

| 描述符偏移 | 首行（`@0x420264 == 0`） | 其余行 |
|---|---|---|
| +0x00 | `(@(0x3F104,L)) \| (@(0x3F108,L)) \| 0x03` | 同左 |
| +0x01 | 入参 `r0h` | 同左 |
| +0x02 | `1` | `0` |
| +0x03…+0x08 | 入参（`er6`/`er1` 派生的 5 字节） | 0 / 递增 |
| +0x09 | `0x02` | 行号低字节 |
| +0x0A | 入参 `r6h` | 0 |
| +0x0B | 入参 `r6l` | 0 |

**按行参数表**：`0x3F104` 与 `0x3F108` 是**两张并行字节数组**，索引 = 当前行号 `@0x420264`，按位或后成为描述符 byte0。
实测内容（`array1@0x3F104`）：

```
行 0..9 : 80 40 20 00 00 10 10 20 40 80
行10..  : 20 2F 3E 4D 5C 6B 7A 89 98 A0 A8 B0 B8 BD C2 C7 CC D0 D4 D8 …
```
**尾部单调递增、步长递减 15→8→5→4** ⇒ 形状上像**逐行曝光时间/光学补偿曲线**（非线性密度补偿）`[推断]`。
首部 0x80,0x40,0x20,0x00,0x00,0x10,0x10,0x20,0x40,0x80 呈**对称 V 形** ⇒ 可能是相邻表的尾部（区域 0x3F000–0x3F130 是一整片表区，`0x3EF30–0x3EF88` 的几何常量也在附近）`[未证]`。

## 4. 每行算术（`0x03C194` → `0x03C1AE` ×4）`[实证]`

```asm
0x03C194  er5 = er0 ; r4l = 0
          循环 4 次：bsr 0x03C1AE(er1=er5, r0l=r4l) ; r4l++
0x03C1AE  r5l = r0l ; er3 = er1 ; er4 = (u32)r5l ; er6 = er4 << 2 ; er3 += er6
          er1 = @er3                 ; 取 32 位
          er0 = sp+0x20 ; jsr 0x018E68
          er1 = @(0x400F32, er6)      ; ★ 第二张表（按 er6 索引）
          er0 = sp+0x18 ; …
```
⇒ 每行做 **4 次**（r4l = 0..3）以 `er1 + 4×r5l` 为索引取表项，经 `0x018E68` 与双精度助手 `0x018AA0`、`0x01876A`（双精度转整）换算。
**`0x018E68` = 移位式 32×32→64 乘法原语**（`r2=0x041F` 移位器计数、`shll.l er3` + `rotxl.w r2` 抽取乘数位；结果 `[er0+0..1]=r2`、`[er0+2..5]=er3`、`[er0+6..7]=e2`）——**不是双精度助手，是整数乘法**。

**五张表 + 位置表的生成者全部在 `0x03A400–0x03BF00` 一个函数簇内**：`0x44908C`（写于 `0x03AD48`）、`0x4491A2`（`0x03A52C/620/768`）、`0x4498F0`（`0x03A646/70C/796/860/920`、`0x03BED8`）、`0x449978`（6 处取址）、`0x4499D8` 位置表（写于 `0x03B65C`，取址 `0x03BA92/0x03BBE2/0x03BD24`）；`0x03B58E` 属同一簇（该簇约 2.5 KB，按分辨率/holder 参数算出每行/每像素的曝光与位置表）。

## 6. 尚未落定的部分（图像算法剩余）

1. **`0x200182-188` 与 `0x200194-19A` 两组 8 个 u16 寄存器的位域含义**——最可能就是曝光时间 / 增益 / 偏置 / gamma / 位深，但**没有位域证据**，`[未证]`。
2. **像素从 ASIC 缓冲（`0x8DC000`）到 RAM 的搬运路径**未追（`0x400416`/`0x448FEE` 的下游写者未定位）。
3. ~~`0x018E68` 的语义~~ → **已解：移位式 32×32→64 乘法原语**；~~五张表的生成者~~ → **已定位：`0x03A400–0x03BF00` 函数簇**（各表写点见 §4）。**仅剩**：`0x400F32` 的生成者、`0x449978`/`0x4498F0`/`0x44908C`/`0x4491A2` 各自的业务含义。
4. **`0x4499D8/0x4499E8` 位置表**的生成规则（`0x03B87C`）与其在扫描中的消费点。
5. **`0x3F104`/`0x3F108` 两数组**的业务名（逐行曝光时间？增益？位深？）。
6. **gamma / 位深转换的算法**（若存在）尚未定位——`0x03A21E`/`0x03A284`/`0x03A2D8` 三个新解出的小函数是候选（各 27–34 条）。
7. `0x4206EC`（扫描档）、`0x41FFA4`、`0x4007C9`（精细/快速）三个模式标志的取值域。
