## 0. 结论速览

| 目标 | 公式 | 模拟器实测 |
|---|---|---|
| `er3`（门限校验对象） | **`BE32(payload[1..4])`** | `0x11223344` |
| `0x400408`（参数暂存主槽） | **`BE32(payload[2..5])`** | `0x22334455` |

## 1. 子功能分派表（`0x026DAE`–`0x026DF4`）

「六数值」**不是**「6 个门限依次校验同一个 V1」，而是**按子功能号（CDB[2]）分派到 12 个分支**，
每个分支各自对 `er3` 做一次等值 / 区间 / 布尔判定。

```
0x026DAE  mov.b  @(0x2,er4), r0l      ; ← 子功能号 CDB[2]
0x026DB2  cmp.b  #0x40, r0l
0x026DB4  beq    0x026df8              ; → er3 == 15354
0x026DB6  cmp.b  #0x41, r0l
0x026DB8  beq    0x026e0a              ; → er3 == 450
0x026DBA  cmp.b  #0x42, r0l
0x026DBC  beq    0x026e1c              ; → er3 == 3283
0x026DBE  cmp.b  #0x80, r0l
0x026DC0  beq    0x026eb6              ; → 放行（无校验）
0x026DC4  cmp.b  #0x81, r0l
0x026DC6  beq    0x026eb6              ; → 放行（无校验）
0x026DCA  cmp.b  #0x91, r0l
0x026DCC  beq    0x026e9c              ; → er3 ∈ {0,1}
0x026DD0  cmp.b  #0x92, r0l
0x026DD2  beq    0x026e9c              ; → er3 ∈ {0,1}
0x026DD6  cmp.b  #0xa0, r0l
0x026DD8  beq    0x026e3e              ; → ±300
0x026DDA  cmp.b  #0xb0, r0l
0x026DDC  beq    0x026eb6              ; → 放行（无校验）
0x026DE0  cmp.b  #0xb3, r0l
0x026DE2  beq    0x026e86              ; → er3 ∈ [-300, 300]
0x026DE6  cmp.b  #0xc1, r0l
0x026DE8  beq    0x026e2e              ; → er3 == 450
0x026DEA  cmp.b  #0xd0, r0l
0x026DEC  beq    0x026eb6              ; → 放行（无校验）
0x026DF0  jmp    0x026eae              ; → 未知子功能
```

### 校验点

```
0x026DF8  cmp.l  #0x00003bfa, er3     ; 15354
0x026E0A  cmp.l  #0x000001c2, er3     ; 450
0x026E1C  cmp.l  #0x00000cd3, er3     ; 3283
0x026E2E  cmp.l  #0x000001c2, er3     ; 450
0x026E86  cmp.l  #0xfffffed4, er3     ; -300
0x026E8E  cmp.l  #0x0000012c, er3     ; +300
0x026E9C  beq    0x026eb6             ; er3 == 0 → 放行
0x026EA0  cmp.l  #0x00000001, er3     ; er3 == 1 → 放行
```

### 落点

| 地址 | 动作 |
|---|---|
| `0x026EB6` | 放行：`mov.b @(0x2,er4), r0l` / `mov.b r0l, @0x400c55`（子功能号存入 `0x400C55`） |
| `0x026EAE` | 拒绝：`mov.w #0x0050, r0` / `mov.w r0, @er6` |
| `0x026E80` | 越界：`mov.w #0x0053, r0` |

### 汇总

| 子功能 | 校验 | 阈值 | 违反 |
|---|---|---|---|
| `0x40` | 等值 | `er3 == 15354` | `0x53` |
| `0x41` | 等值 | `er3 == 450` | `0x53` |
| `0x42` | 等值 | `er3 == 3283` | `0x53` |
| `0x80` | — | **无校验** | — |
| `0x81` | — | **无校验** | — |
| `0x91` | 布尔 | `er3 ∈ {0,1}` | `0x53` |
| `0x92` | 布尔 | `er3 ∈ {0,1}` | `0x53` |
| `0xA0` | 区间 | `±300` | `0x53` |
| `0xB0` | — | **无校验** | — |
| `0xB3` | 区间 | `er3 ∈ [-300, 300]` | `0x53` |
| `0xC1` | 等值 | `er3 == 450` | `0x53` |
| `0xD0` | — | **无校验** | — |
| 其他 | — | — | `0x50` |

⇒ **12 个分支、6 个不同校验值、其中 4 个子功能完全不校验。**

## 2. `er3` 的装载链（`0x026D10`–`0x026D74`）

```
0x026D10  sub.l  er3, er3
0x026D12  mov.b  @(0x1,er5), r3l     ; payload[1]
0x026D16  mov.b  r3l, r3h
0x026D18  sub.b  r3l, r3l
0x026D1A  mov.w  r3, e3              ; e3 = payload[1]<<8
0x026D1C  sub.w  r3, r3
0x026D1E  sub.l  er0, er0
0x026D20  mov.b  @(0x2,er5), r0l     ; payload[2]
0x026D24  mov.w  r0, e0              ; e0 = payload[2]<<8
0x026D26  sub.w  r0, r0
0x026D28  add.l  er0, er3
0x026D2A  sub.l  er0, er0
0x026D2C  mov.b  @(0x3,er5), r0l     ; payload[3]
0x026D30  shll.l #2, er0   (×4)      ; payload[3]<<8
0x026D38  add.l  er0, er3
0x026D3A  sub.l  er0, er0
0x026D3C  mov.b  @(0x4,er5), r0l     ; payload[4]
0x026D40  add.l  er0, er3
0x026D42  sub.l  er0, er0
0x026D44  mov.b  @(0x5,er5), r0l     ; payload[5]
0x026D48  mov.b  r0l, r0h
0x026D4A  sub.b  r0l, r0l
0x026D4C  mov.w  r0, e0              ; e0 = payload[5]<<8
0x026D4E  sub.w  r0, r0
0x026D50  sub.l  er1, er1
0x026D52  mov.b  @(0x6,er5), r1l     ; payload[6]
0x026D56  mov.w  r1, e1              ; e1 = payload[6]<<8
0x026D58  sub.w  r1, r1
0x026D5A  add.l  er1, er0
0x026D5C  sub.l  er1, er1
0x026D5E  mov.b  @(0x7,er5), r1l     ; payload[7]
0x026D62  shll.l #2, er1   (×4)      ; payload[7]<<8
0x026D6A  add.l  er1, er0
0x026D6C  sub.l  er1, er1
0x026D6E  mov.b  @(0x8,er5), r1l     ; payload[8]
0x026D72  add.l  er1, er0
0x026D74  mov.l  er0, @(0xe,sp)     ; 存栈
```

> **注**：这是**解析层**（`0x026BF8`）的装载链，与**执行层**（`0x0269A6`）的
> `0x400408` 组装链是**两处独立实现**，各自产出同一个 32 位大端数。
> 两处独立复现出完全一致的结果 ⇒ 不可能是编译器系统性缺陷。
> （此前 `agent_b3` §2.8 标为「实证」的「`<<16` 怪癖」即源于对这两处的误读。）

模拟器实测：`er3 = 0x11223344` = `BE32(payload[1..4])` ✓

## 3. `0x400408` 的三个写入点

C1 臂 `0x026A86` / A0 臂 `0x026AC4` / B3 臂 `0x026B46` **结构同构**。

A0 臂完整链：

```
0x026A92  sub.l  er0, er0
0x026A94  mov.b  @(0x2,er6), r0l     ; payload[2]
0x026A98  mov.b  r0l, r0h
0x026A9A  sub.b  r0l, r0l
0x026A9C  mov.w  r0, e0              ; e0 = payload[2]<<8
0x026A9E  sub.w  r0, r0
0x026AA0  sub.l  er1, er1
0x026AA2  mov.b  @(0x3,er6), r1l     ; payload[3]
0x026AA6  mov.w  r1, e1              ; e1 = payload[3]<<8
0x026AA8  sub.w  r1, r1
0x026AAA  add.l  er1, er0            ; er0 += payload[3]<<8
0x026AAC  sub.l  er1, er1
0x026AAE  mov.b  @(0x4,er6), r1l     ; payload[4]
0x026AB2  shll.l #2, er1   (×4)      ; payload[4]<<8
0x026ABA  add.l  er1, er0
0x026ABC  sub.l  er1, er1
0x026ABE  mov.b  @(0x5,er6), r1l     ; payload[5]
0x026AC2  add.l  er1, er0
0x026AC4  mov.l  er0, @0x400408
```

B3 臂多一条前置：`0x026B0A mov.b @(0x1,er6), r0l` / `0x026B0E mov.b r0l, @0x400412`
（payload[1] 单独存入 `0x400412`）。

模拟器实测：`0x400408 = 0x22334455` = `BE32(payload[2..5])` ✓（C1/A0/B3 三臂结果一致）

### 第 4 个写入点机制不同

`0x028D94`（片夹识别区）：

```
0x028D80  mov.l  @0x4204e8, er1
0x028D88  shlr.l er1                ; 算术右移 1
0x028D8A  mov.l  @0x420308, er2
0x028D92  add.l  er1, er2
0x028D94  mov.l  er2, @0x400408
```

这是**两处 RAM 值的算术**，与 payload 无关 ⇒ `0x400408` 是**被多方复用的暂存槽位**，
不是单一含义的字段。

## 4. `0x40040C` 的公式

A0 臂 `0x026AD8`–`0x026AFE` 与 B3 臂 `0x026B5E`–`0x026B80` 结构同构：

```
0x026ADC  mov.b  @(0x7,er6), r1l     ; payload[7]
0x026AE0  mov.w  r1, e1              ; e1 = payload[7]<<8
0x026AE4  add.l  er1, er0
0x026AE8  mov.b  @(0x8,er6), r1l     ; payload[8]
0x026AEC  shll.l #2, er1   (×4)      ; payload[8]<<8
0x026AF4  add.l  er1, er0
0x026AF8  mov.b  @(0x9,er6), r1l     ; payload[9]
0x026AFC  add.l  er1, er0
0x026AFE  mov.l  er0, @0x40040c      ; ← 32 位写入
```

⇒ **`0x40040C` = `(payload[7]<<16) + (payload[8]<<8) + payload[9]`**
（模拟器实测 `0x00778899` ✓）

⚠️ `mov.l er0, @0x40040c` 是 **32 位写入**，一次覆盖 `0x40040C`–`0x40040F`
⇒ `0x40040E`/`0x40040F` 是它的低半部分。

### 5.2 参数块组装器（`0x02BC00`）

把散落槽位重新拼成 16 字节块：

```
0x02BC00  mov.b  @(0x2,er5), r0l     ; payload[2]
0x02BC06  mov.b  r0l, @(0x6,er6)     ; → 块 +0x06
0x02BC0A  mov.b  @(0x3,er5), r5l     ; payload[3]
0x02BC0E  mov.b  r5l, @(0x7,er6)     ; → 块 +0x07
0x02BC12  mov.b  @0x400410, r0l
0x02BC18  mov.b  r0l, @(0x8,er6)     ; → 块 +0x08
0x02BC1C  mov.b  @0x400411, r0l
0x02BC22  mov.b  r0l, @(0x9,er6)     ; → 块 +0x09
0x02BC26  mov.b  @0x400413, r0l
0x02BC2C  mov.b  r0l, @(0xa,er6)     ; → 块 +0x0A
0x02BC30  mov.b  @0x400414, r0l
0x02BC36  mov.b  r0l, @(0xb,er6)     ; → 块 +0x0B
0x02BC3A  mov.b  @0x400412, r0l
0x02BC40  mov.b  r0l, @(0xc,er6)     ; → 块 +0x0C
0x02BC44  sub.b  r0l, r0l
0x02BC46  mov.b  r0l, @(0xd,er6)     ; → 块 +0x0D = 0
0x02BC4A  mov.b  #0xff, r0l
0x02BC4C  mov.b  r0l, @(0xe,er6)     ; → 块 +0x0E = 0xFF
0x02BC50  mov.b  r0l, @(0xf,er6)     ; → 块 +0x0F = 0xFF
0x02BC54  mov.l  #0x00006010, er4    ; ← 接着从 ROM 0x6010 取 17 B 模板
```

紧接 `0x02BC54` 从 ROM `0x6010` 取 17 B 模板 ——
与 `LS8000-E0总表` §2 记录的「`0xB3` 作业组装 33 B 参数块 @`0x400CA0`，
`+0x10..+0x20` 取 ROM `0x6010` 模板 17 B」吻合。

⇒ **`0x400408`–`0x400414` 是一组「按字段拆散存放、组装时再拼回」的暂存槽位**，
这统一解释了为什么 `0x400408` 会有多个来源完全不同的写入点。

## 7. 为什么人工推导会错（方法论教训）

打包阶段我曾把这里的公式推错一次，整篇结论作废。**两处错误**：

| # | 错误 | 事实 | 为什么会错 |
|---|---|---|---|
| 1 | `4 × shll.l #2` = 左移 **16** 位 | 每次移 **2** 位，4 次共 **8** 位 | 「4 条 × 4」与「4 条 × 2」容易混；直觉上 4 字节拼 32 位会想要 8+8+8+8 |
| 2 | `@(0x2,er6)` 是 payload[**1**] | 是 payload[**2**] | `er6` 指向 CDB 基址，而 payload 另存于 `0x400C55` 区；两者下标基准不同 |

**为什么必须模拟执行**：
人工推导要同时追踪「寄存器高低半字」「字节搬移」「移位」「立即数」四层语义，
任一层判断错，位段分配就全错，且**结果看起来仍然自洽**（不会报错）。
而模拟器**直接执行指令**、读出实际值 —— 没有中间推理，不可能骗过自己。

**方法**：新建 `h8sim.py`（H8 指令子集模拟器），用真实 ROM + 真实解码结果
喂入可区分的 payload，直接读出 `0x400408` / `0x40040C` / `er3`，
再**反推**公式并与候选式比对。

**通用教训**：**凡涉及「字节 → 位段」映射的结论，必须用模拟执行验证，
不能靠人工推导**。同样的错误在 `agent_b3` §2.8（「`<<16` 怪癖」）也出现过一次。
