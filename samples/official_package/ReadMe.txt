Nikon Firmware Update Software***************************************************************************************************Caution: Please read the following important information before using the update software***************************************************************************************************Caution: Running the update softwareBefore performing the update, ensure that the power cables for both scanner and computer and the interface cable or cables connecting the two devices are securely connected.After starting the updater, do not perform any of the operations below until a message appears stating that the update is complete.  Depending on their timing, any of these actions could damage the firmware, making it impossible to download it to the scanner:¥	Turning the scanner or host computer off¥	Disconnecting the interface cable¥	Performing any operation on the host computer, including moving the mouse¥	Connecting or disconnecting other IEEE1394 devices or turning them on or off (note that some IEEE1394 devices turn off automatically if no operations are performed for a specified period; such devices should be disconnected from the computer before the update begins)The update takes approximately one minute to complete.***************************************************************************************************1. Contents of This Software Package  This Software  package contains the following files:  ¥ Readme file (this file)  ¥ Firmware update software manual     ¥ Manual_en_8000.pdf (pdf file)  ¥ Update software (executable file)      ¥ SUPERCOOLSCAN8000ED_111.exe (update software for SUPER COOLSCAN 8000 ED film scanners)2.
