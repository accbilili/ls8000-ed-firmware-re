# RAM 字节 `0x4003FB` 访问点定论（任务 F4）

镜像：`D:\DS\TEST\LS8000\LS8000_111_ROM.bin`（228,345 B，地址 = 文件偏移 + `0x10000`）
反汇编：`h8dis.py` + `h8.lst`，全部结论可由下方地址逐条复现。
分级：`[实证]` 有字节/反汇编证据；`[推断]` 逻辑自洽无直接验证；`[未证]` 仅线索。

**一句话**：`0x4003FB` 是一个**单字节「片夹识别状态/结果码」**，编码域 `0x10–0x1F` 与 `0x81`，`0x10` = 初值/正常；它不是标志位、也不是计数器 —— `[实证]`（写值全集 + 三张以 `(v-0x10)` 为索引的分派表）。

### 1.4 无效 / 误归类命中

- 直接段 27 条**无一条无效**：无重复 PC、无「看似该地址实为邻址」、无数据区误命中（27 条均可从指令边界解码出完整 6 字节 `6A 28 00 40 03 FB`）。
- 普查把 5 条 `mov.l #0x004003fb,erN` 记入「未对齐/非操作数命中（离群）」，**归类错误**：它们是合法指令（`7A 0N` + 4 B 立即数）的**立即数操作数**，本身不是访问点，但派生 15 条真实访问。正确处理应为「指针基址候选」，而不是丢弃（见 §2.3）。

### 2.3 复核发现的错误（已在本报告内改正）

1. **`rows.json` / `rows_md.txt` 与本变量无关**（严重）。两者是 `0x03E390` 主机码映射表的 85 条记录（`host_code / field2 / 记录地址 / flags / 载荷`），不含任何 `0x4003FB` 访问行。所谓「已整理的行数据」并不存在，本报告 §1 的访问表是**重新从 `out_census.txt` + 原镜像重建**的。

## 3. 三函数判据

### 3.1 `0x02753E` —— 判据在 `0x02759E`，间接由 `0x400D79` 门控

```
0x027556  mov.b @0x4206EC,r0l ; bne 0x0275B4      ; 非零 → 走别路
0x027562  mov.w @er5,r0 ; cmp.w #0x0E10/#0x3000/#0x2000 ; 已有效则跳过
0x02757A  mov.b @0x400D72,r0l ; cmp.b #0x01 ; beq 0x02758C
0x027584  mov.w #0x9000,r0 ; mov.w r0,@er5        ; 否 → 报 0x9000
0x02758C  mov.b @0x400D79,r0l ; cmp.b #0x01 ; beq 0x02759E
0x027596  mov.w #0x5000,r0 ; mov.w r0,@er5        ; 否 → 报 0x5000
0x02759E  mov.b @0x4003FB,r0l
0x0275A4  cmp.b #0x10,r0l
0x0275A6  bne 0x0275AE                              ; ≠0x10 → r0=0
0x0275A8  mov.w #0x1100,r0
0x0275AC  bt 0x0275B0                               ; T=Z=1（相等）→ 保留 0x1100
0x0275AE  sub.w r0,r0                               ; r0=0
0x0275B0  mov.w r0,@er5                             ; 两分支汇合，同一写点
```
- 判据：`cmp.b #0x10`（**不是** `tst`、**不是** `bt/bclr` 位测试；全 42 个访问点中无一处使用 `tst` 或位操作）。
- 两分支去向：**相等** → `r0=0x1100` → `0x0275B0` 写 `@er5`；**不等** → `r0=0` → 同一 `0x0275B0` 写 `@er5`。之后 `0x0275B2 bt → 0x0275B8`。
- 附加门控：仅当 `0x400D72==1` 且 `0x400D79==1` 才走到这条判据；否则分别上报 `0x9000` / `0x5000`。`@er5` 已是 `0x0E10/0x3000/0x2000` 时直接跳过本段。

### 3.2 `0x027E20` —— 本点无判据，是**写点**，被 `r6l==1` 门控

```
0x027E0E  cmp.b #0x01,r6l ; bne 0x027E5E    ; 模式≠1 → 跳过写
0x027E12  mov.b #0x01,r0l ; bsr 0x027A54
0x027E18  bset #1,@er4                      ; 0x400404 bit1
0x027E1C  mov.w e6,@er5                     ; e6=0x9000
0x027E1E  mov.b #0x10,r0l
0x027E20  mov.b r0l,@0x4003FB               ; 写 0x10（无条件、常量）
0x027E26  mov.b #0x05,r0l → 0x400D72        ; 阶段 5
0x027E30  mov.b #0x01,r0l → 0x400D79        ; 片夹在位
```
- 判据：`cmp.b #0x01, r6l`（入口模式字节），**对 `0x4003FB` 本身无任何比较**。
- 两分支去向：`r6l==1` → 顺序执行到 `0x027E20` 写 `0x10`，随后 `0x027E46 bt`（T 来自 `cmp`，相等为 1）跳到 `0x027E5E`；`r6l!=1` → 直接 `0x027E5E`。

## 4. 取值集合定性（用写入值全集）

| 写点 | 写入值来源 | 值 |
|---|---|---|
| `0x027A24` | `0x027A22 mov.b #0x10` | `0x10` |
| `0x027B50` | `0x027B4E mov.b #0x10` | `0x10` |
| `0x027E20` | `0x027E1E mov.b #0x10` | `0x10` |
| `0x027EA0` | `0x027E9E mov.b #0x10` | `0x10` |
| `0x027EB4` | `0x027EB2 mov.b #0x10` | `0x10` |
| `0x02859E` | `0x02859C mov.b #0x10` | `0x10` |
| `0x028BB4` | `bsr 0x028E30`（入参 `0x80`）返回 `r0l` | `0x10–0x1F` / `0x81` |
| `0x028C02` | `bsr 0x028E30`（入参 `0x81`）返回 `r0l` | `0x10–0x1F` / `0x81` |

`0x028E30` 的返回码（`0x028FF6–0x02908C` 逐条读出，`[实证]`）：

```
0x80 路径（0x028FFE–0x029046）：0x0F→0x11  0x08→0x12  0x0A→0x13  0x02→0x14  0x03→0x15
                              0x04→0x16   0x06→0x17  0x05→0x18  0x07→0x81
0x81 路径（0x029052–0x02908A）：0x08→0x19  0x0A→0x1A  0x09→0x1B  0x0B→0x1C
                              0x0C→0x1D  0x0E→0x1E  0x0D→0x1F
默认     ：0x10（0x02908E mov.b #0x10,r0l，所有 rts 前的兜底）
```
（`0x029086 mov.b #0x1E`、`0x02908A mov.b #0x1F`、`0x02908C bt`、`0x02908E mov.b #0x10` 均在 `0x029090` 汇合后 `rts`。）

**定性结论**：
- 写入值全集 = `{0x10} ∪ {0x11…0x1F} ∪ {0x81}`，**全部是离散编码，无递增/递减**；42 个访问点中**无一条** `inc/dec/add` 作用在本地址上。
- 因此**不是计数器**（无递增值），**不是 0/1 标志**（值域 >2 且 `0x10` 为基）。
- 它是**状态/结果枚举**：`0x10` = 初值/正常/就绪，`0x11–0x1F` = 识别过程中的缺陷/异常类别，`0x81` = 需要第二遍（`0x81` 路径）的中间态。
- 三张表用 `(v-0x10)` 做索引，进一步确证「`0x10` 是基址值」：`0x3E62C`（`0x24` B/条，`sub #0x240`=`0x24×0x10`，`0x02408E`）、`0x3E86C`（`0x13` B/条，`sub #0x130`=`0x13×0x10`，`0x0240CC`）、跳转表（`add.b #0xF0` + `cmp.b #0x0F`，`0x024338`/`0x0290E6`）。

- `0x40043C–0x40043F` 是**纯读区**（CDB 镜像），与 `0x4003FB` 无耦合。

- `0x4003FB` 与 `0x4003FC` 是明确的「当前状态 / 上一次状态」对偶（`0x0279C2–0x0279CA`：读两者，不等才更新影子并 `bset #4,@er6`）。这是**结构体字段**最强的正面证据。

## 6. 结论与反证条件

**结论**：`0x4003FB` 是「片夹识别状态/结果码」单字节 —— 写值恒为 `0x10`（复位/就绪）或 `0x028E30` 的诊断返回码 `0x11–0x1F / 0x81`；读侧全部做等值/区间比较（`cmp.b #0x10/0x12/0x14/0x15/0x16/0x17/0x18` 与 `0x10–0x1F` 区间检查），并被 3 张表以 `(v-0x10)` 为索引分派；`0x02753E@0x0275A4` 用 `cmp.b #0x10` 决定上报 `0x1100` 还是 `0`。`[实证]`（写值全集 + 表索引归一化 + 42 个访问点全量核对）
其中「`0x1100` = 片夹已识别/正常」属 `[推断]`。

**反证条件**（任一成立即需改写定性）：
1. 在引导块 `0x0–0xFFFF` 或任何未覆盖区找到对 `0x4003FB` 的 `inc/dec/add` 或递进写 → 改判「步骤计数器」。
2. 找到 16/32 位访问别名覆盖该字节（如 `mov.w r0,@0x4003FA`、`mov.l r0,@0x4003F8`）→ 降级为「某字的低字节」。当前 32 处立即数引用全查无此形态，但引导块与中断向量区未纳入镜像。
3. 若证明 `0x3E62C` / `0x3E86C` 的索引不是 `(v-0x10)`（例如 `v<0x10` 时也合法索引）→ §4/§5 的「基值 `0x10`」论据失效。
4. 若主机侧 `0x03E390` 记录或 `0x1100` 的消费方显示 `0x1100` 表示「识别失败」而非「就绪」→ 极性反转（`0x10` 变成故障态）。
5. 若发现 DMA/DTC 描述符把 `0x4003FB` 作为目标地址 → 存在非指令写，写值全集不完整。
