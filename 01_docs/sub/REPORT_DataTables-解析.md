## 0. 结论速览

补齐了 `0x03E508 / 0x03EBA0 / 0x03EBC0 / 0x03ED60 / 0x03F7xx` 五处表，并**打通一条两级分派链**：

```text
主机码（u16）──→ 0x03E390 映射表 ──→ 内部索引（u16）
                                      ↓
                            0x03EBC0 记录表（索引 → 处理函数 + 参数长度 + 数值范围）
                                      ↓
                                  0x25B2C–0x264C2 区间内的具体处理函数
```

这条链条此前未被识别，它解释了「主机命令如何找到固件处理函数」，与 Harness 已解的 `0x03E2E8`（20 条 SCSI CDB[0] 分派）是**两条并列路径**：`0x03E2E8` 按 SCSI opcode 索引，`0x03E390` 按内部主机码索引。

## 5. `0x03E508` — 图像缓冲地址表 + 参数描述表

前 16 字节为 4 个 ASIC 图像缓冲基址：

```text
0x008E8000   0x008ED000   0x008F2000   0x008F7000   （间隔 0x5000 = 20 KB）
```

与 Harness 已确认的 ASIC 图像存储（`0x00800000–0x008FFFFF`）一致，是其中 4 个 20 KB 缓冲。

`0x03E518` 起为参数描述记录（Harness 称 10 条），实测**非固定长度**（id 出现间隔为 0x4/0x8/0xC/0x10 混合）。已确认 id 序列：`0x00, 0x80, 0x81, 0x84, 0x87, 0x88, 0x8A, 0x8C, 0x8D, 0xE0`，与 Harness 给出的 10 条一致。**记录内部字段布局未能唯一确定**，保留为未解。
