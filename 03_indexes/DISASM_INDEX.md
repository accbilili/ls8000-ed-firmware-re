## 2. `fix36_summary.txt` 结构与 36 组函数表

### 2.1 文件结构

`fix36_summary.txt`（10,398 行 / 361,341 B）由 `fix36.py` 生成，结构为：

```
B16 复走结果
<空行>
fn 0x022F4E  旧空洞 1  修复版指令 812  新解出 152
    ---
       0x022F50  mov.b     @(0x1,er0), r2l      ← 上下文窗口（前后各 3 条）
       0x022F54  mov.l     @(0x440,sp), er0
       ...
    >> 0x022F60  mov.l     er1, @(0x43c,sp)     ← 「>>」标记 = 新解出指令
    ...
    ---
    ... 下一条新解出指令的上下文窗口 ...
fn 0x023066  旧空洞 1  修复版指令 214  新解出 21
...
```

- **统计行格式**：`fn 0x<6位HEX>  旧空洞 <n>  修复版指令 <n>  新解出 <n>`
- **上下文块**：每条「新解出」指令附带前后各 3 条可解码指令；`>>` 前缀标记该行本身是新解出的
- **合计**：36 组 · 42 个旧空洞 · 8,927 条修复版指令 · **1,299 条新解出**

**它记录了什么**：`fix36.py` 用 `cfg_v4.json` 的 `owner` 映射找出所有「旧解码器解不出、修复版能解出」的指令地址（**洞点**），按 owner 分组归并成 36 组伪入口，对每组用修复版解码器从组首地址做递归复走（线性流 + 分支目标入队，`rts` 停，`jsr/bsr` 记边不展开），然后把「旧版解不出、新版解得出」的指令逐条连同上下文写进本文件。

## 8. 结论与遗留

### 8.1 结论

1. **规模**：**61 份**产物 / **1,334.1 KB**；A 类 **52 份 684,833 B**、B 类 6 份 533,200 B、C 类 3 份 149,281 B。
2. **36 组函数**：`fix36_summary.txt` 记录每组的旧空洞数 / 修复版指令数 / 新解出数，并为每条新解出指令附前后 3 条上下文；36 组的语义已逐条与实际 asm 对齐（见 §2.2）。
3. **调用边**：`edges.json` 12 组 / **146 边**（call **72** / bcc **52** / jmp **22**）；合并 36 组 `fix_*.asm` 后共 513 条 call 边，关键跨簇链已列出（§3.2），E0→C1→作业层链路已字节级核实（§3.3）。
4. **抽样质量**：**通过**。4 份抽样 0 个 `.byte` / 0 个非法助记符 / 0 个 `undefined` / 0 个 `None`，且逐行重解码与磁盘产物完全一致；全量 61 份同样 0 命中。
5. **解码器修复量**：**实测确认 42 洞点 / 36 组函数 / 1,299 条不可见指令被恢复**（去重后 1,067 条唯一指令），`.byte` 断点 47 → 0，可见指令 5,696 → 8,927。

### 8.2 遗留 / 待办

1. **`edges.json` 应更正**：`40->02AAAE` → `40->02AEAA`（补算已备好，见 §6.2），本轮未改动原文件。
2. **`f_*.asm` 清单应补 `f_03A3D4.asm`**（A0 扫描启动，382 条指令）。
3. **36 组是 `cfg_v4.json` 的 owner 伪入口**，9 组区间重叠（重复率 1.29×）；若需「唯一函数」口径，需先做函数边界归并。
4. **18 个被调目标语义仍为「未知」**（`_verify\sem_table.json` 的 `calls` 字段标记为「未知助手」）：`0x0119A6`、`0x01280C`、`0x0170A0`、`0x01842C`、`0x018708`、`0x0188D2`、`0x018E54`、`0x027260`、`0x02726E`、`0x0272D6`、`0x027362`、`0x028676`、`0x029DBA`、`0x02DAB2`、`0x031B20`、`0x032D2C`、`0x03B4F4`（另 `0x02D700` 本身就是 36 组之一，非外部助手）。
5. **1,067 条唯一新解出指令的语义尚未逐条展开**——其中含「图像算法 60%」那块的核心算术（`0x030000` 88 条 / `0x0354DE` 114 条 / `0x0315A8` 93 条 / `0x03B87C` 97 条 四组合计 392 条，占 37%）。
