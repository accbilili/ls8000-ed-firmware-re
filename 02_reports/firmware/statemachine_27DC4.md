## 1. 函数边界与结构

### 1.1 真实起止（不采用 CFG 的 `0x027F24`）

| 项 | 值 | 证据 |
|---|---|---|
| 入口 | `0x027DC4` | `01 00 6D F3  mov.l er3,@-sp` + `01 20 6D F4  stm.l er4-er6,@-sp`，标准 H8 序言，两条连续入栈 [`实证`] |
| 唯一 `rts` | `0x027F22`（`54 70`） | 函数体内无第二个 `rts`；唯一的 `jmp`（`0x027E0A jmp 0x027f1a`）跳向本函数自己的返回序列，不是外部出口 [`实证`] |
| 函数体 | `[0x027DC4, 0x027F22]`，半开区间 `[0x027DC4, 0x027F24)` | 序言→`rts` 单一出入，104 条指令（与清单头 `insns=104` 一致）[`实证`] |
| 栈帧 | 16 B（`er3` 4 B + `er4-er6` 12 B）；另有 2 B 传参槽 | `0x027E4A mov.w r0,@-sp` / `0x027E58 adds.l #2,sp` [`实证`] |

**`0x027F24` 不是本函数的终点，而是下一个函数入口**：

- `0x027F24` 自带序言 `6D F6 mov.w r6,@-sp`，自带 `rts` 在 `0x027F42`，范围 `[0x027F24, 0x027F44)` [`实证`]
- 它被本函数以 `bsr` 调用：`0x027F0C  55 16  bsr 0x027f24`（`bsr d:8`，目标 = `0x027F0C+2+0x16`）[`实证`]
- 内部再调 `0x02896C`（`bsr 0x027F34`）与 `0x027F44`（`bsr 0x027F38`）

> 结论：`0x027F24` 是**真子函数**（后置钩子，写 `0x02B87C(0x00E2)` 关驱动配置、清 `0x41FFD4` 起的 10×0x22 B 槽位数组）。
> CFG 把 `0x027F24` 记为 `0x027DC4` 的边界，是把"半开区间右端"误当成"函数末尾地址"，看报告时须按 `0x027F22` 理解。

### 1.2 `0x027E20` 判决：既不是内部标签，也不是子函数

**结论：`0x027E20` 是一条 6 字节指令的起始地址，在控制流图上无入边。**

| 判据 | 事实 | 分级 |
|---|---|---|
| 1. 指令对齐 | 前一条 `0x027E1E F8 10 mov.b #0x10,r0l` 占 2 B，`0x027E20` 恰为下一条 `6A A8 00 40 03 FB mov.b r0l,@0x4003FB`（6 B）的字节起点 | [`实证`] |
| 2. 无调用 | 全 CFG 27,215 条指令中，`bsr`/`jsr`/`jmp` 目标等于 `0x027E20` 的：**0 条** | [`实证`] |
| 3. 无分支 | 条件分支目标集合中无 `0x027E20`：**0 条**（本函数所有分支目标为 `0x027DF4/0x027E00/0x027E0E/0x027E48/0x027E5E/0x027E9A/0x027ED2/0x027F0E/0x027F18/0x027F1A`） | [`实证`] |
| 4. 非入口形态 | 该处无寄存器保存、无栈调整，是一条普通存储指令，且必须由 `0x027E12`（`mode==1`）顺序流入 | [`实证`] |

误判成因：`0x027E12`–`0x027E45` 是"常量预置块"，形如 `F8 xx`（置立即数）+ `6A A8 00 40 0D xx`（存绝对地址）严格交替，任意从块中间某条指令起解的线性扫描都会得到同一条指令序列（因为恰好字节对齐），于是被切出一个"函数入口"。若某份 CFG 把 `0x027E20` 列为函数起点，那是最典型的**线性切分假阳性**（本轮错误认知清单 `10.3` 同类问题）。

## 3. 状态机还原

### 3.1 判决：不是"显式状态变量 + switch"

- 函数体内**没有任何持久状态变量**：唯一的模式量是 `r6l`（入口 `r0l` 搬入，`0x027DE4 mov.b r0l,r6l`，高位由 `0x027DD0 sub.b r6h,r6h` 清 0），是**调用参数**，函数返回后不保留 [`实证`]。
- 模式分发用的是**条件分支链**（`cmp.b #0x01,r6l` / `cmp.b #0x02,r6l`），不是跳转表、也不存在被反复读写的状态单元 [`实证`]。
- 因此本函数是**"顺序流程 + 轮询等待"**，等待点只有 B5 一个。

**mode 取值全集与实际取值**：

| mode | 行为 | 位置 | 是否有调用者传入 |
|---|---|---|---|
| `0` | B9 额外置 `0x400406` bit0，走完整收尾 | `0x027EA8` `mov.b r6l,r6l` / `bne` | **无**（3 个调用点只传 1 和 2）[`实证`] |
| `1` | B4 预置 → B5 → 清 `0x400D78` → B10 → 报状态 0 → 返回 1 | `0x027E0E` | 有：`0x027748`、`0x02776C` |
| `2` | 跳过 B4（直接进 B5）→ B8 直接 `jmp 0x027F18` 返回 1 | `0x027E9A beq 0x027f18` | 有：`0x0276EC`（`r4l=2`，`0x02767A`） |

### 3.2 步骤序列（A → B → C …）

| 步 | 动作 | 地址 | 退出条件 |
|---|---|---|---|
| **A** | 保存寄存器、装载 `0x4202B4`/`0x400406`/`0x400404`、记 mode | `0x027DC4–0x027DE4` | 无条件 |
| **B** | 行程上限闸门（见 4.3） | `0x027DE6` | 返 1 继续；返 0 → **失败 F1**（`0x0E00`） |
| **C** | 片仓传感器 B 去抖 | `0x027DF4` | 返 1 继续；返 0 → **失败 F2**（`0x0E10`） |
| **D** | `mode==1` 时执行进片预置（状态字 `0x9000`、`0x4003FB=0x10`、`0x400D72=0x05`、`0x400D79=0x01`、清 `0x40041A`、`0x400D78=0x01`） | `0x027E0E–0x027E46` | 无条件（其它 mode 跳过） |
| **E** | 走片：`while (@0x4202A2 != @0x4202B4) { 走到 @0x4202B4; 等状态 }` | `0x027E48–0x027E68` | 位置相等 |
| **F** | 位置账本 `0x4202EC += 0x55` | `0x027E6A` | 无条件 |
| **G** | B 轴回 0（目标 `0x0`，钳位 `0x0F60`）并等待 | `0x027E78–0x027E8C` | 状态达标 |
| **H** | 收尾：`mode==2` 直接返回 1；否则清 `0x400D78`(mode1)、重写四常量、`0x9000`、快照 `0x4202B2/0x4202FC`、条件调 `0x027F24`、`mode==1` 报状态 0、返回 1 | `0x027E8E–0x027F22` | 无条件 |

失败路径（B/C 任一失败）：`0x027E00 mov.w r0,@er5`（`0x400404`）→ `0x027E02 mov.b #0x03,r0l` → `0x027E04 bsr 0x027A54` → `0x027E08 sub.b r0l,r0l` → `jmp 0x027F1A` 返回 **0**。
成功返回 **1**（`0x027F18 mov.b #0x01,r0l`）；`0x027E0A jmp 0x027f1a` 跳过 `0x027F18`，故错误路径返回 0 [`实证`]。

### 3.3 真正的显式状态机在别处（重要）

本函数的直接上层 `0x027676` 会先读状态字节 `0x420300`，非 0 且非 1 就跳过状态机；为 0/1 才进 `0x0277CE`：

| 状态变量 | 取值全集 | 迁移点 | 依据 |
|---|---|---|---|
| `0x420300` | `0`（初始）、`3`、`4`、`5` | `0→3`：`0x02781A`（等 `0x02D000` 三键齐）；`3→4`：`0x027892`；`3→0`：`0x02789E`（超时 `0x04B0`=1200）；`4→5`：`0x0278B0`；`5→0`：`0x027916`（超时 `0x01F4`=500） | [`实证`] |

`0x027DC4` 与该状态机**无耦合**：不读不写 `0x420300`，只在 `0x027676` 的 `0x420300 ∈ {0,1}` 分支里被 `bsr` 调用 [`实证`]。

> 备注：`0x0277CE` 的两个超时常量 `0x04B0`（`0x027852`，比较 `0x4003F6` 时间戳差）与 `0x01F4`（`0x0278E4`）属于**按键/传感器确认窗**，不是走片超时，勿混。

## 4. 时序与超时

### 4.1 等待与轮询（本函数内）

| 项 | 地址 | 事实 | 分级 |
|---|---|---|---|
| 走片循环条件 | `0x027E5E–0x027E68` | `mov.w @0x4202a2,r0` / `mov.w @er3,r1`（`er3=0x4202B4`）/ `cmp.w r1,r0` / `bne 0x027e48` → **位置相等才退出** | [`实证`] |
| 循环体内无计数器 | `0x027E48–0x027E5C` | 只有 `mov.b r6h,r0l`、压参、装 `0x186A0`、`jsr 0x02ADCE`、`jsr 0x02ACE6`；**无 `inc/cmp` 计数比较** | [`实证`] |
| A 轴状态轮询 | `0x02ACE6–0x02AD06` | 期望值 `r6 = (@0x4202A9==0) ? 0 : 7`；`while (@0x4202A4 != r6) jsr 0x010B56` | [`实证`] |
| B 轴状态轮询 | `0x02C8E0–0x02C902` | 期望值同上式，轮询 `0x4202EE`；触发字节 `0x4202F3` | [`实证`] |

`0x027DC4` 传给 `0x02ADCE` 的隐含参数：`r0h=0`（`0x027E48 mov.b r6h,r0l` 压栈 → `0x02AE36 mov.b @(0x1d,sp),r0h` → `0x02A3A6 mov.b r5h,@0x4202A9`），即**恒期望状态 0（正常完成）**，从不期望 7 [`实证`]。

### 4.2 走片时限：软件无超时，靠硬件定时器

| 环节 | 地址 | 常量/动作 | 分级 |
|---|---|---|---|
| 时限入参 | `0x027E4C` | `mov.l #0x000186A0, er1` = **100000**，随 `jsr 0x02ADCE` 传入 | [`实证`] |
| 透传 | `0x02ADD8` `mov.l er1,er3` → `0x02AE2E` 压栈 → `0x02A328 mov.l @(0x14,sp),er0` | 原样带到运动原语 | [`实证`] |
| 换算 | `0x02A510` `#0x3E8`（×1000）、`0x02A51A` `#0x280`（÷640） | `100000×1000÷640 = 156250` 个计数 | [`实证`] |
| 装载 | `0x02A524` `mov.l #0x0044084c,er1` + `bsr 0x02B1E4`；`0x02A53C mov.w @0x44084e,e0` + `bsr 0x02B22E` | 写 `0x44084C`/`0x44084E`（片内定时器通道） | [`实证`] |
| 启动 | `0x02A546` `mov.b #0x01,r0l` → `mov.b r0l,@0x4003fe`；`0x02A54E` `bset #3,@0xffffc0` | 使能 + 起定时器 | [`实证`] |
| 超时后的表现 | `0x4202A4 = 7` | 由 `0x02ACE6`/`0x02C8E0` 判定"异常完成"，本函数不接受 7 | [`推断`]（谁写 7 未定位，见第 7 节） |

> **判据结论**：本函数**没有"超时计数器比较的立即数"**。唯一的时间量是 `0x186A0`=100000（经 ×1000÷640 变 156250 计数装进 `0x44084C/0x44084E`）。
> 需注意：`0x02ADCE` 内另有 `0x0172`（370）门限与 `0x2710`（10000）/`0x09C4`（2500）两档常量，那是**按距离选速度档**，不是超时阈值：

```asm
02ADFE  sub.w  r5, r6              ; r6 = |目标-当前|
02AE00  cmp.w  #0x0172, r6         ; 370
02AE04  bcs    0x02ae0c
02AE06  mov.w  #0x2710, e6         ; ≥370 → 10000
02AE0C  mov.w  #0x09c4, e6         ; <370 → 2500
02AE2C  sub.l  er5, er5
02AE2E  mov.l  er3, @-sp           ; 0x186A0
02AE32  mov.l  er5, @-sp
02AE3A  mov.w  e6, r1              ; 速度档 → r1
02AE3C  mov.w  r6, e0              ; 距离 → e0
02AE3E  mov.b  r4l, r0l            ; 方向
02AE40  bsr    0x02a2f6
```

速度档最终落到 `0x4202A0`（`0x02A34A mov.w r3,@0x4202a0`）[`实证`]。B 轴对称：门限 `0x012F`（303），档位 `0x02BC`（700）/`0x0190`（400），落 `0x4202EA`（`0x02BE7C`），目标钳位 `0x0F60`（3936，`0x02C9F6`）[`实证`]。

### 4.3 行程闸门（`0x029CD8`）—— 唯一的"上限比较"

```asm
029CF0  mov.w  @0x4202ec, r0       ; 位置账本
029CF6  mov.w  #0x000c, e0         ; ★ 12
029CFA  mulxu.w e0, er0            ; ×12
029CFC  mov.w  @0x4202a2, r1       ; 当前编码器位置
029D02  add.w  r0, r1              ; r1 = 当前位置 + 12×账本
029D06  mov.b  @0x4003fb, r0l      ; ★ 模式/分辨率索引
029D0C  shll.l er0                 ; ×2 → 字偏移
029D0E  mov.w  @(0x3ee10,er0), r0  ; ★ 上限表
029D16  cmp.w  r0, r1
029D18  bcs    0x029d26            ; r1 < 上限 → 返 1 放行
029D1A  jsr    0x02cfe0            ; 越限：再做 0xFFFF55 bit4 去抖
029D20  bne    0x029d26
029D22  sub.b  r0l, r0l            ; 去抖通过 → 返 0（超限）
```

| 量 | 值 | 说明 | 分级 |
|---|---|---|---|
| 乘法常量 | `0x000C` = 12 | 账本 × 12 | [`实证`] |
| 索引变量 | `0x4003FB` | 本函数写 `0x10`；`0x028590/0x02859E` 先把旧值存 `0x4003FC` 再置 `0x10` | [`实证`] |
| 表基址 | `0x3EE10`，取字 `0x3EE10 + 2×0x4003FB` | `0x4003FB=0x10` → `0x3EE10+0x20`；`0x029D0C` 是 `10 30`，`h8.lst` 记 `1030 shll.l r32l` = 1 位移位（2 位移位另有 `1050/1070`），故 ×2 成立 [`实证`] |
| 上限值 | `0x3EE30 = 0xA410` = **42000** | 对应 `0x4003FB=0x10` | [`实证`] |
| 相邻表项 | `0x3EE32=0x300C`(12300)、`0x3EE34=0xA3AC`(41900)、`0x3EE36=0x8EF8`(36600) | 逐级下降的行程上限族 | [`实证`] |
| 越限去抖 | `0x02CFE0`，`0xFFFF55` bit4，`cmp.w #0x0014`（20 次） | 连续 20 次采样 | [`实证`] |

> 该表**不是**从 `0x3EE10` 起对齐存放的：`0x3EDF0–0x3EE2B` 是**另一张 6 字节记录表**
> （`{u32 处理器地址, u8 子功能码, u8 填充}`，9 条：`0x41→0x02AEAA`、`0x42→0x02B98A`、`0x81→0x02CB66`、
> `0xA0→0x028648`、`0xB0→0x03A3D4`、`0xC1→0x027F24`、`0xD0→0x02BA24`、`0x80→0x02866E`、`0xB3→0x028722`）[`实证`]。
> 指令里的基址 `0x3EE10` 只是锚点：只有 `0x4003FB ≥ 0x10` 时才落到 `0x3EE30` 起的字表，`0x4003FB=0x10` 正好命中首项。
> 因此 `0x4003FB` 的有效取值只能是 `≥0x10`。`0x4003FB` 语义记为"分辨率/模式索引"属 [`推断`]，其值域全集 [`未证`]。

### 4.4 失败/超时后置什么状态、错误码写哪

| 场景 | 状态字写点 | 值 | 上报 | 返回 |
|---|---|---|---|---|
| 行程闸门失败 | `0x027E00 mov.w r0,@er5`（`er5=0x400404`） | `0x0E00`（`0x027DEE`） | `0x027A54(3)` | `0` |

`0x027A54`（状态上报）落点表 [`实证`]：

| 状态码 | 分支指令 | 写点 | 值 |
|---|---|---|---|
| 任意 | — | `0x027A66 mov.b r2l,@0x4206c8` | 状态码本身 |
| `0` | `0x027A86 beq 0x027a96` | `0x027A96 bset #0,@0xffff6f` | 只置标志位 |
| `1` | `0x027A8A beq 0x027a9c` | `0x027A9C mov.l #0x313,er0` → `0x027AAA mov.l er0,@er4`（`0x4206CE`）；`0x027AB2/0x027AB6` 再写 `0x4206CA ← @0x4003F6` | 787 + 时间戳 |
| `2` | `0x027A8E beq 0x027aa4` | `0x027AA4 mov.l #0x64,er0` → `0x4206CE`；`0x4206CA ← @0x4003F6` | 100 + 时间戳 |
| `3` | `0x027A92 beq 0x027abc` | `0x027ABC`–`0x027AE4` | `0x4206CE=0x64`(100)、`0x4206CA=@0x4003F6`、`0x4206D2=@0x4003F6`、`0x4206D6=0xFA0`(4000) |

> 状态 `1` 与 `3` 都写 `0x4003F6` 时间戳，状态 `1` 额外把 `0x313`（787）留在 `0x4206CE`；
> `0x313`/`0x64`/`0xFA0` 是"窗口长度/重试值"类标量，语义 [`推断`]。

错误码还可被上层读成对外状态（`0x02753E`，非本函数）：

027564  cmp.w  #0x0e10, r0         ; 传感器失败 → 继续执行命令

这一段既是 `0x4003FB` 决定"报 `0x1100` 还是 `0`"的**直接证据**（`0x0275A8 mov.w #0x1100,r0` / `0x0275AE sub.w r0,r0`），也说明 `0x400404` 是跨模块共享的状态字 [`实证`]。

## 5. 调用关系

### 5.1 直接调用点：3 处，全在 `0x027676` 内

`bsr` 是相对跳转，绝对地址搜不到。做法：取 `cfg_v4.json` 的 27,215 条已解码指令，逐条取 `bsr` 的**已解析目标**统计。该 JSON 对每条 `bsr` 都存了第 6 字段（十进制绝对目标），三个调用点均为 `163268 = 0x027DC4`，命中 3 条；`jsr/jmp` 目标等于 `0x027DC4` 的为 0 条。可复现：`[v for v in ins.values() if v[1]=='bsr' and v[2]=='0x027dc4']`。

| 调用点 | 指令 | 传入 mode | 前置条件 |
|---|---|---|---|
| `0x0276EE` | `5C 00 06 D2  bsr 0x027dc4`（= `0x0276F2+0x06D2`） | `2`（`0x0276EC mov.b r4l,r0l`，`r4l=2` 于 `0x02767A`） | `0x400D72==5` 且 `0x420300==0/1` 且 `0x02CFA0(bit5)==1` 且 `0x4202FE!=1` 且 `0x4207FA==1` 且 `0x02CFC0(bit7)==1` |
| `0x02774A` | `5C 00 06 76  bsr 0x027dc4` | `1`（`0x027748 mov.b #0x01,r0l`） | `0x400D72!=5` 分支，且 `0x4207FA==1` 且 `0x02CFC0==1` |
| `0x02776E` | `5C 00 06 52  bsr 0x027dc4` | `1` | `0x400D72!=5` 分支，且 `0x02CF60(bit2)==0` 且 `0x02CFA0(bit5)==0` |

调用后的处理并不一致 [`实证`]：清 `0x4207FA` 只发生在前两处（`0x0276F4`、`0x027750`，`er5=0x4207FA`）；写 `0x420244 = 0xFF` 只发生在后两处（`0x027752`、`0x027772`）；第三处（`0x02776E`）既不跳转也不清标志，直接落进 `0x02777A` 的 `0x400D77` 门控。

### 5.2 完整上层链

```
0x027DC4  (本函数, mode∈{1,2})
  ↑ bsr ×3            : 0x0276EE / 0x02774A / 0x02776E
0x027676  装片驱动步骤（E0 worker step）
  ↑ bsr ×1            : 0x02755E
0x02753E  E0 worker 主循环
  ↑ jmp 自身          : 0x027670 jmp 0x02753e（死循环，函数体末尾 0x027674 rts 不可达）
  ↑ fall-through      : 0x0274BC 块 → 0x027526 写 0x4202B2/0x4202FC → 落进 0x02753E
0x02740A  E0 worker 主体（无任何 bsr/jsr 调用者）
  ↑ 任务表登记        : 0x010920 / 0x010934
```

任务表（`0x010948` 按 `0x4003FA` 选一张，`0x010952`/`0x01095C` 装基址）：

| 表基址 | 记录（10 B：栈顶 u32 / 入口 u32 / 标志 u16） | 依据 |
|---|---|---|
| `0x010920` | `0x480000 → 0x020A5A`；`0x470000 → **0x02740A**` | `0x01096C–0x01097A` 取值、`0x01099A mov.l er3,@er1` 存 `0x4003EE` [`实证`] |
| `0x010934` | `0x480000 → 0x010F5C`；`0x470000 → **0x02740A**` | 同上 [`实证`] |

> 即 `0x02740A` 是**独立任务入口**，栈顶 `0x470000`（与启动期 `er7=0x478000` 同区），两套引导路径都登记同一条进片任务。`0x4003FA` 的语义 [`未证`]（两表仅入口不同）。

## 7. 未解决的疑问（≤5）

1. **谁写 `0x4202A4 = 7`**：`0x02ACE6`/`0x02C8E0` 用它表示"异常完成"，但全 CFG 只有 7 条读（`0x016E94`、`0x016EAE`、`0x028682`、`0x02ACD0`、`0x02ACFC`、`0x02AFD0`、`0x02B014`）与 1 条写（`0x02AC48`，值恒为 `0`，紧接 `0x02AC46 sub.b r0l,r0l` 的清零例程）。**不存在写 7 的直接指令**，只能来自指针间接写或 CFG 未覆盖区。下一步：查 `0x4003FE`（`0x02A548` 置 1）与 `0xFFFFC0` bit3 对应的定时器/中断向量处理程序。
2. **`0x4202B4` 无非零写入者**：4 字节常量只出现 3 次（`0x027BBC` 写 0、`0x027D12` 读、`0x027DD3` 装入 `er3`）。若恒为 0，则 E5 步等价于"回 0 位"；否则其写入在 CFG 空洞区（`0x027B90–0x027DC4` 整段无 owner，本报告已用线性解码补出并在 `0x027DC4` 精确收口）。下一步：补齐 `0x027900–0x027DC4` 段的函数归属，确认是否存在 `mov.w r0,@(4,er?)` 的间接写。
3. **`0x4003FB` 值域全集**：表基址 `0x3EE10` 与有效项 `0x3EE30` 之间存在 0x20 字节非同类数据，暗示取值 ≥0x10，但仅见 `0x10` 一个实际值（`0x02859E`、`0x027E20/EA0/EB4`）。下一步：找 `0x4003FB` 的其它写入者（16 处引用中 `0x016C16/0x016C20/0x016C2A` 三条连续读可疑）。
4. **`0x4003FA` 的语义**：`0x010948` 用它二选一任务表（`0x010920` vs `0x010934`），两者仅 `0x020A5A` / `0x010F5C` 不同，`0x02740A` 相同。下一步：查 `0x4003FA` 写入点与启动路径（段1/段2）的对应关系。
5. **`0x42029F` / `0x4207F8` 双条件（`0x027EF8`）含义**：决定是否执行后置钩子 `0x027F24`。`0x4207F8` 在 `0x0274BE` 被置 1、`0x02742C` 被读，`0x42029F` 未见写点。下一步：沿 `0x02742A` 分支回溯 `0x42029F`。
